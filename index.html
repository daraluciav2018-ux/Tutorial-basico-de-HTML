Tema 1

¿Qué es HTML?

HTML significa HyperText Markup Language. Es el lenguaje que se usa para crear la estructura de las páginas web. Funciona por medio de etiquetas, que se escriben entre los signos < y >.

Tema 2

Estructura de una página

La etiqueta <html> encierra todo el documento. En <head> va la información de la página, como el título, y en <body> va todo lo que se ve en pantalla.

Tema 3

Títulos y párrafos

Los títulos se crean con las etiquetas <h1> hasta <h6>, siendo <h1> el más grande. Los párrafos se escriben con la etiqueta <p>.

Tema 4

Listas

Hay dos tipos principales de listas:

  • <ol> lista ordenada, con números.
  • <ul> lista desordenada, con viñetas.

Cada elemento se escribe con <li>.

Tema 5

Enlaces

Los enlaces permiten ir a otra página o a otra parte de la misma página. Se crean con la etiqueta <a> y el atributo href, donde va la dirección de destino.

Tema 6

Imágenes

Las imágenes se agregan con la etiqueta <img>. El atributo src indica dónde está la imagen y alt la describe por si no se puede mostrar.
