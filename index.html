1. ¿Qué es HTML?

HTML significa HyperText Markup Language (Lenguaje de Marcado de Hipertexto). Es el lenguaje que se usa para crear la estructura de las páginas web. Funciona por medio de etiquetas, que se escriben entre los signos < y >.

2. Estructura de una página

Toda página HTML tiene una estructura básica. La etiqueta <html> encierra todo el documento. En <head> va la información de la página, como el título. En <body> va todo lo que se ve en pantalla.

3. Títulos y párrafos

Los títulos se crean con las etiquetas <h1> hasta <h6>. El <h1> es el más grande y el <h6> el más pequeño. Los párrafos de texto se escriben con la etiqueta <p>.

Volver al inicio

4. Listas

En HTML hay dos tipos de listas principales:

  • Lista ordenada <ol>: muestra los elementos con números.
  • Lista desordenada <ul>: muestra los elementos con viñetas.

Cada elemento de la lista se escribe con la etiqueta <li>.

5. Enlaces

Los enlaces permiten ir a otra página o a otra parte de la misma página. Se crean con la etiqueta <a> y el atributo href, donde se coloca la dirección a la que se quiere ir.

Volver al inicio

6. Imágenes

Para mostrar una imagen se usa la etiqueta <img>. El atributo src indica dónde está guardada la imagen y el atributo alt describe la imagen por si no se puede mostrar.
